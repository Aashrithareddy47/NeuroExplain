### Quick Start
- **Backend**: `cd NeuroExplain/backend && source venv/bin/activate && uvicorn app.main:app --reload --port 8000`
- **Frontend**: `cd NeuroExplain/frontend && npm run dev`
- **Tests**: `cd NeuroExplain/backend && source venv/bin/activate && pytest -v`
